This is an typeical probelm which can be solved by topological sort and dynamic programming.

Let us analyze the text first.

Actually you will realize that if you think about dynamic programming in graphical way, especially when you think that if we let every step of dp(It is 100% true for Deterministic Dynamic Programming you don't have to know what is that right now) as a node, the combination of each state is just a DAG graph.
Think about that: we have no way to go back when we want to back to previous nodes/states, which means the
general processs can olny go fowarwrd. Very satisfied rules of dp.

So we can use dp to solve this graph problem.

You may still confusing about why a vaild graph should not has any cycle.
The answer is easy. The problem mentioned "If the value can be arbitrarily large, output -1 instead."
In what case, the result can be such large? The answer is if a graph has a(or more) cycle.
To be specific: if you are the person who want make a path whose value is the largest, what will you do if you find a cycle? Surely, you will go through this cycle over and over agian, which means you even can get a almost infinitly large number in the long run!
Threfore, In order to get a vaild result, we need a graph satisfied that there is no single cycle.
After such sort of analyze, we conclude that we are able to use dp in that probelm.
Since we also need to check cycle in the graph, we can also implement kahn(A kind of topological sort).
So, I decide use dp + kahn to slove this problem.


Now it is the time to think how to define a dp state.
Back to the problem: "We define a path's value as the number of the most frequently occurring letter. For example, if letters on a path are "abaca", then the value of that path is 3
. Your task is find a path whose value is the largest."
One way to design the state is that set dp[i][j], i in range [1,n],j in range[1,26], such that dp[i][j] means a route end up with node i, the number of accumlated characters from 'a' to 'z'
Then we just have to implement kahn algorithm to the graph. Specifically, if when we process the top element of the queue;node v is at the top of the queue; dp[v][s[v]-'a']++, which means we count the character of node v.
Then when we trverse the adjacent list of v; for every node u that can be arrived from v: dp[u][c] = max(dp[u][c],dp[v][c])

Here is the input code segment. let's find out how to write function kahn()

```c++
void kahn() {
    queue<size_t> q;
    ll cnt = 0;
    for (size_t i = 1; i < indegrees.size(); ++i) {
        if (indegrees[i] == 0) {
            q.push(i);
        }
    }
    while (!q.empty()) {
        cnt++;
        size_t v = q.front();
        q.pop();
        dp[v][s[v-1] - 'a']++;
        for (ll u : graph[v]) {
            indegrees[u]--;
            if (indegrees[u] == 0) {
                q.push(u);
            }
            for (size_t c = 0; c < 26; c++) {
                dp[u][c] = max(dp[u][c], dp[v][c]);
            }
        }
    }


    if (cnt < indegrees.size()-1) {
        cout<<-1;
    }
    else {
        ll ans = 0;
        for (size_t i = 1; i <= indegrees.size()-1; ++i) {
            for (size_t j = 0; j <= 25; ++j) {
                ans = max(ans, dp[i][j]);
            }
        }
        cout<<ans;
    }
}
```
