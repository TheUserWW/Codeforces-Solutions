This is an typeical probelm which can be solved by topological sort and dynamic programming.

Let us analyze the text first.

Actually you will realize that if you think about dynamic programming in graphical way, especially when you think that if we let every step of dp as a node, the combination of each state is just a DAG graph.
Think about that: we have no way to go back when we want to back to previous nodes/states, which means the
general processs can olny go fowarwrd. Very satisfied rules of dp.

So we can use dp to solve this graph problem.

You may still confusing about why a vaild graph should not has any cycle.
The answer is easy. The problem mentioned "If the value can be arbitrarily large, output -1 instead."
In what case, the result can be such large? The answer is if a graph has a(or more) cycle.
To be specific: if you are the person who want make a path whose value is the largest, what will you do if you find a cycle? Surely, you will go through this cycle over and over agian, which means you even can get a almost infinitly large number in the long run!
Threfore, In order to get a vaild result, we need a graph satisfied that there is no single cycle.
After such sort of analyze, we conclude that we are able to use dp in that probelm.
Since we also need to check cycle in the graph, we can also implement kahn(A kind of topological sort).
So, I decide use dp + kahn to slove this problem.
