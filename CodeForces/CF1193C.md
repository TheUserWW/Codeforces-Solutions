# [CodeForces 1195 C. Basketball Exercise](https://codeforces.com/contest/1195/problem/C)

This is a classic dynamic programming problem. I will demonstrate three approaches to solve it using DP techniques.

## Problem Analysis

### Key Constraints

When selecting students, we must follow these restrictions:

1. Choose players from left to right (increasing indices).
2. The index of each chosen player must be strictly greater than the previous player's index.
3. No two consecutive chosen students can be from the same row.
4. Maximize the total height of all chosen students.

### DP State Design

To solve this, we design a state that satisfies two fundamental properties:

1. **Completeness**: Each state clearly reflects all the constraints above.
2. **Optimality**: Each state is independent of future decisions (optimal substructure).

The second property is crucial to dynamic programming: we derive optimal results from optimal previous cases.

## First Solution: Two-Row DP

### State Definition

Define `dp[i][j]` as the maximum total height achievable at index `i` when performing operation `j`, where:

- `j = 0`: Pick a player from row A at position `i`
- `j = 1`: Pick a player from row B at position `i`
- `j = 2`: Skip picking a player at position `i`

The answer is `max(dp[n][0], dp[n][1], dp[n][2])`.

### Base Cases

**When `i = 0`** (no players selected yet):
$$dp[0][0] = dp[0][1] = dp[0][2] = 0$$

**When `i = 1`** (first decision):
- `dp[1][0] = rowA[0]` (pick from row A)
- `dp[1][1] = rowB[0]` (pick from row B)
- `dp[1][2] = 0` (skip)

### State Transition

#### For `dp[i][0]` (picking from row A):

At position `i`, if we pick from row A, the height increases by `rowA[i-1]`. The previous move **cannot** be picking from row A (consecutive constraint). We can:
- Pick from row B at `i-1`: `dp[i-1][1]`
- Pick from row A at `i-2`: `dp[i-2][0]`
- Skip at `i-1`: `dp[i-1][2]`

$$dp[i][0] = \max(dp[i-1][1], dp[i-2][0], dp[i-1][2]) + rowA[i-1]$$

#### For `dp[i][1]` (picking from row B):

By symmetry with row A:

$$dp[i][1] = \max(dp[i-2][1], dp[i-1][0], dp[i-1][2]) + rowB[i-1]$$

#### For `dp[i][2]` (skipping):

No restrictions when skipping:

$$dp[i][2] = \max(dp[i-1][0], dp[i-1][1], dp[i-1][2])$$

**Note**: We use `i-1` indexing because DP arrays are 1-based while input arrays are 0-based.

## Implementation

```cpp
#include <bits/stdc++.h>
using namespace std;
#define ll long long

void setIO(string name = "") {
    ios_base::sync_with_stdio(0);
    cin.tie(nullptr);
    if (!name.empty()) {
        freopen((name + ".in").c_str(), "r", stdin);
        freopen((name + ".out").c_str(), "w", stdout);
    }
}

int main() {
    setIO();
    int n;
    cin >> n;
    
    vector<ll> rowA(n), rowB(n);
    for(ll i = 0; i < n; i++) {
        cin >> rowA[i];
    }
    for(ll i = 0; i < n; i++) {
        cin >> rowB[i];
    }
    
    // dp[i][j]: max height at position i with operation j
    vector<vector<ll>> dp(n + 1, vector<ll>(3, 0));
    
    // Base case: i = 1
    dp[1][0] = rowA[0];  // Pick from row A
    dp[1][1] = rowB[0];  // Pick from row B
    dp[1][2] = 0;        // Skip
    
    // State transitions
    for(ll i = 2; i <= n; i++) {
        dp[i][0] = max({dp[i-1][1], dp[i-2][0], dp[i-1][2]}) + rowA[i-1];
        dp[i][1] = max({dp[i-2][1], dp[i-1][0], dp[i-1][2]}) + rowB[i-1];
        dp[i][2] = max({dp[i-1][0], dp[i-1][1], dp[i-1][2]});
    }
    
    // Output the maximum height
    cout << max({dp[n][0], dp[n][1], dp[n][2]}) << "\n";
    
    return 0;
}
```

**Key Points**:
- Time Complexity: **O(n)**
- Space Complexity: **O(n)** (can be optimized to **O(1)** using rolling arrays)
- DP arrays are 1-indexed for easier state transitions
- Input arrays are 0-indexed as per standard convention
