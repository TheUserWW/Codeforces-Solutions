This is a very typical dynamaic programming problem. In this reading, I will show you three ways to solve this problem using dynamic programming.

First, we have to analyze the problem. According to the context, we know that there are 2 restriction we have to follow when we choose students:
    1. Choose players from left to right.
    2. index of each chosen player (excluding the first one taken) will be strictly greater than the index of the previous player.
    3. Demid chooses students in such a way that no consecutive chosen students belong to the same row.
    4. The total height of all chosen students is maximum possible. 


    
According to thses conditions, we can try to define states for dybnamic programming.
When we desgin a state, we have to make sure that each states fullfill 2 foundemental featres:
    1. Each states can clearly reflect the restrition that given above
    2. Each state are independnet with future.
The second condition is particularly important since the key point of dynamic programming is that we deduce the optimal 
result from deduce the optimal previous case. In other words, we have to make sure that previous calculation is 100% get 
optimal result, so dynamic programming can work.


First solution:
So, let's make things esay, since we can only choose people from left to right, one of a very intuatuive way to
define a state is that we can firstly define dp[i] which means optial combination when we are choosing poeple at 
position i. However, dp[i] lack of information about which row we choose. Therefore, we need a 2 dimention dp array
to define a state dp[i][j] so that we can clearly describe what excatly happened at i.

Specifically, I defined dp[i][j] as when we going to the index i, what is the optimal result if we choose to
implement j opeartion. It sound a little bit abstract, but actually is very clear.
j is a integer in the interval [0,2]
j = 0 means we pick up a player from row A.
j = 1 means we pick up a player from row B.
j = 2 means we give up to pick a player at i (yeah, we can relly do this).

Again, the meaning of dp[i][j] is that the optimal combination (maximum possible total height of players) we can get
when we reach the ith index, implementing opeartion j.

In the end, the result would be max({dp[n,0],dp[n,1],dp[n,2]})
