[CodeForces - 938D](https://codeforces.com/contest/938/problem/D)

This is a shortest path problem. In this problem, we are intend to find minimum number of coins a person from city i has to spend to travel to some city j. 
One of the most useful algorithm to solves this is dijkstra algorithm, but we have to make slight changes to the orginal version.

Just like it said, j is not a definate vertex, whcih means we just to make sure that we find a path start from i and ends with a arbitray j( j may equals to i) so that we have to spend minimum cost.
Thanks for the feature of dijkstra algorithm, once we implemant that for a starting point i, we just get shortest path from i to any other points.
That is a very essential feature since it can allow as to avoid implementing dijkstra algorithm for all given vertexs.

   2.Write core part
   That is the most important step. Let us find out how to implement dijksra specifically in this problem.
   we konw that the time complexity of dijksra is O(n(n+m)logn).
   If we really just implement dijksra for every single element, the time complexity will become O(m*nlongn)
   It is an very inefficient time complexity.
   So how can we avoid this?
   The esaist way to do is that we only implement dijksra one time, but process all vertexs simuteaously.
   In that case, the time complexity would back to O((n+m)l//ogn).
   I belive you would feel confusing about how can I make it.

   Firstly, lets write function head:
   ```c++
   void dijkstra(auto& graph, auto& price) {}
   ```
   At this momment, I have to say that there is a little difference from classic shortest path problem since according to the problem reading, we have to buy a ticket at city i. Putting this rule in general case,
   we can deduce that every city i has "weight". Therefore, even at start point, our cost is greater than 0. Instead we have to let dist[i] = price[i], which means if we start at point i, we have to pay price[i]
   amount of cost at first.
   ```c++
   .....
   size_t n = graph.size()-1;
   vector<ll> dist(n+1,LLONG_MAX);
   priority_queue<pair<ll,ll>, vector<pair<ll,ll>>,greater<>> pq;
   for (int i = 1; i <= n; i++) {
         dist[i] = price[i];
         pq.emplace(dist[i],i);
   }
   .....
   ```
   Then, you can just imply dijksra like normal way
   ```c++
   while (!pq.empty()) {
      auto [w,v] = pq.top();
      pq.pop();
      if (w != dist[v]) {
         continue;
      }
      for (auto [u,d] : graph[v]) {
            if (dist[u]  > dist[v] + 2LL*d) {
                dist[u] = dist[v] + 2LL*d;
                pq.emplace(dist[u],u);
            }
        }
    }
    for (int i = 1; i <= n; i++) {
        cout << dist[i] << " ";
    }
   ```
