[CodeForces - 938D](https://codeforces.com/contest/938/problem/D)

This is a shortest path problem. In this problem, we are intend to find minimum number of coins a person from city i has to spend to travel to some city j. 
One of the most useful algorithm to solves this is dijkstra algorithm, but we have to make slight changes to the orginal version.

Just like it said, j is not a definate vertex, whcih means we just to make sure that we find a path start from i and ends with a arbitray j( j may equals to i) so that we have to spend minimum cost.
Thanks for the feature of dijkstra algorithm, once we implemant that for a starting point i, we just get shortest path from i to any other points.
That is a very essential feature since it can allow as to avoid implementing dijkstra algorithm for all given vertexs.
